- [PySide6 6.11.2 官方源码](https://download.qt.io/official_releases/QtForPython/pyside6/PySide6-6.11.2-src/)
- [Qt 6.11.2 官方源码与模块](https://download.qt.io/official_releases/qt/6.11/6.11.2/)
- [Qt for Python 组件许可说明](https://doc.qt.io/qtforpython-6/licenses.html)
