# ClipNest

ClipNest 是一个使用 Python、PySide6 和 SQLite 编写的 Windows 剪贴板管理器。它在本机记录文本、代码、链接、邮箱、颜色和图片，方便以后搜索、收藏和再次复制。应用没有服务器、账号、遥测或在线 AI 功能。

默认全局快捷键是 `Ctrl + Alt + V`。快捷窗口显示时保留当前应用的输入焦点；用鼠标单击记录，会复制内容并尝试粘贴到原软件的输入框。

## 启动

开发环境需要 Windows 10/11 和 Python 3.12 或更新版本。打包后的目录版不需要另外安装 Python。

在项目根目录打开 PowerShell：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1
```

如果本机安装的是其他符合要求的 Python 版本，用相应解释器创建 `.venv` 即可。激活虚拟环境不是必需步骤，以上命令始终使用项目自己的解释器。

目录版启动时，双击 `dist\ClipNest\ClipNest.exe`。移动或分发程序时，需要保留整个 `ClipNest` 文件夹及其 `_internal` 子目录。

## 使用方式

复制内容后，ClipNest 会添加历史记录。启动时不会读取剪贴板已有内容，开始监听后只处理新的复制事件。重复复制同一内容会更新使用时间，保留原来的收藏、置顶、名称、备注和标签。图片单独存储，数据库保存路径和元数据。

单次采集的文本或 HTML 最多接受 200 万字符，图片最多接受 2500 万像素。超限时跳过本次记录并提示，不截断内容。复制本地文件时，不读取文件内容，也不把本地文件路径当作文本历史。

管理窗口分为导航栏、历史列表和详情区。在详情区可以复制、收藏、置顶和删除记录。"整理信息" 用来修改名称、备注、标签、分组、内容类型和语言；"编辑原文" 用来修改文本内容。代码预览保留原始缩进和换行，手动选择语言只影响识别和显示，不会执行代码。

快捷窗口会保持置顶，点击其他软件后仍然显示。只有主动点击搜索框才进入搜索；此时上下方向键选择记录，Enter 复制并粘贴，Esc 关闭。默认发送粘贴快捷键后继续显示，可在设置中勾选 "粘贴后自动关闭快捷浮窗"，发送成功后收起窗口。也可以点击右上角的 "关闭" 收起快捷窗口。

右键记录可以置顶、收藏、删除，或选择 "仅复制"。自动粘贴先等待 Enter 与 Ctrl、Alt、Shift、Win 松开，再恢复目标窗口并发送 Ctrl+V。焦点已切换、目标已关闭或权限不足时，界面会提示，内容仍保留在剪贴板，可自行按 Ctrl+V。应用不主动运行代码，也不模拟 Enter；目标软件如何处理粘贴内容由该软件决定。管理窗口中的双击仍只复制记录。

每条记录右侧都有删除按钮。普通记录点击后直接删除；收藏或置顶记录会先确认。"批量选择" 用来勾选多条记录，再点 "删除选中"；批量删除和 "删除全部历史" 都先确认，默认保留收藏与置顶。批量删除会在数据库事务中检查当前保护状态，列表尚未刷新时也会保留新收藏或置顶的记录。批量点选、右键整理和点击删除按钮不会触发粘贴。

按住顶部的 "ClipNest" 标题或标题旁的空白区域可以拖动窗口，松开后保存位置。再次呼出或重启后会恢复这个位置；如果原来的显示器已断开，窗口会回到当前可见屏幕。

快捷窗口支持即时搜索、分类过滤、收藏和置顶筛选。中文使用子串匹配，英文和代码关键词同时使用 SQLite FTS5 搜索。全局快捷键冲突时，应用会提示修改设置。

文本工具先显示处理结果。支持去除多余空格、清理换行、大小写转换、去重行、JSON 格式化和复制纯文本。可以复制结果或保存为新记录，原记录不会被自动覆盖。

关闭管理窗口默认收起到托盘。托盘菜单可以重新打开管理窗口、暂停或恢复监听、打开设置，以及完全退出应用。收藏与置顶是独立状态，任一状态开启都会保护记录免于自动清理。默认普通历史上限为 2000 条，按最近复制时间保留 30 天，可在设置中调整。

## 插画主题

浅色主界面使用冰蓝色、白色和顶部横幅插画；黑色主界面保留深蓝选中效果，右侧展示竖版插画的局部。查看图片记录时，这张装饰图会隐藏。历史列表和详情区保持清楚的文字背景。

侧栏的最近记录、全部历史、收藏夹、代码片段、自定义标签、文本工具和设置使用缩小后的表情图标，底部暂停按钮使用第八个表情。导航文字保留，置顶记录仍可通过列表上方的筛选框查看。

快捷窗口在浅色模式下使用暖白底，标题区放置抱猫插画。常用类型按钮与原来的类型、时间、收藏和置顶筛选都可使用。插画不接收鼠标或键盘焦点，顶部标题仍可拖动。收藏为空时显示暖色插画，搜索无匹配内容时显示无结果提示。

主题素材随程序保存在包内，加载不依赖启动目录，不再从原图片临时路径读取，也不联网获取图片。

## 本地数据与隐私

默认数据目录是 `%LOCALAPPDATA%\ClipNest`。可以指定另一个目录：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\run.ps1 -DataDir "D:\ClipNest 数据"
```

设置中可以调整排除应用、历史上限、保留天数、主题、快捷键、开机自启和粘贴后自动关闭。托盘菜单可以暂停记录。管理窗口底部提供导入、导出和清空历史；清空默认保留收藏与置顶，可以勾选同时删除这些受保护记录。应用排除依据 Windows 提供的进程信息，密码管理器的复制方式可能不同，不能保证识别所有密码、验证码或复制来源。使用敏感内容前，可直接暂停记录。

剪贴板历史和导出文件包含复制过的原文及图片。本版本没有数据库加密，请把数据目录和导出文件放在自己的受保护目录中。应用不保存剪贴板内容日志；状态提示中的异常只显示异常类型或通用错误信息。

更换数据目录或手工备份前，请从托盘完全退出应用，再复制整个数据目录。SQLite 在运行期间可能同时存在数据库、WAL 和 SHM 文件，仅复制数据库文件可能遗漏尚未写回的内容。日常迁移优先使用应用提供的导出和导入功能。

## 项目结构

```text
ClipNest/
├─ clipnest/
│  ├─ core/        # 数据库、搜索、分类、文本处理和业务模型
│  ├─ platform/    # Windows 快捷键、进程识别、开机自启
│  ├─ ui/          # 主窗口、快捷窗口、设置和文本工具
│  └─ assets/      # 包内插画、侧栏贴纸与来源说明
├─ tests/          # 核心规则、持久化和 GUI/Windows 集成测试
├─ scripts/
│  ├─ run.ps1
│  ├─ build.ps1
│  ├─ generate_icon.py
│  └─ installer.iss
├─ docs/RELEASE.md
├─ run_clipnest.py
├─ requirements.txt
└─ pyproject.toml
```

GUI、剪贴板监听和数据库访问各有职责。耗时的数据库搜索和图片存储通过后台任务完成，界面线程负责 Qt 控件和剪贴板交互。数据库初始化包含版本迁移，SQL 查询使用参数绑定。

## 测试与打包

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe run_clipnest.py --smoke-test
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
```

`--smoke-test` 用隔离的测试流程检查启动和退出，并关闭真实剪贴板采集。不指定数据目录时，测试自动创建临时目录并在结束后清理。需要保留截图和结果时，可以同时指定 `--data-dir`，这个目录必须不存在或为空；测试拒绝写入已有记录的目录。`--quit-after 10` 会在 10 秒后退出普通运行；这个参数本身不会关闭监听。

真实剪贴板的 OLE 恢复诊断曾发生崩溃，原剪贴板恢复未获确认。相关诊断脚本和 pytest 真实剪贴板测试已停用；当前可复现的原生焦点与拖动脚本使用模拟复制和粘贴，不访问系统剪贴板。具体测试结果见发布与验收说明。

`build.ps1` 生成默认不显示控制台的目录版。排查启动异常时，可以加 `-Console` 生成带控制台的版本。构建脚本调用 [PyInstaller 官方命令选项](https://pyinstaller.org/en/stable/usage.html)，显式收集 Pygments 的语言和样式模块；Qt 打包依赖由 PyInstaller 的 PySide6 hooks 处理，相关说明见 [Qt for Python 部署文档](https://doc.qt.io/qtforpython-6/deployment/deployment-pyinstaller.html)。

本轮插画更新的自动化测试为 240 项通过、2 项跳过，目录版构建退出码为 0。打包后的 EXE 已在 Windows 的隔离目录完成启动检查：5 条合成记录和 8 个侧栏图标加载成功，单屏、150% 缩放。浅色主窗口、黑色主窗口与浅色快捷窗口的打包版截图已检查。

桌面交付程序和源码已更新，199 个打包文件与构建产物的 SHA256 逐一一致。复制更新和桌面隔离测试前后，用户历史数据库哈希保持一致，未覆盖原历史。桌面 EXE 的隔离启动通过；普通托盘启动后连续 59.1 秒保持响应、单实例锁存在。这是短时间检查，不能代替长时间后台运行验收。
